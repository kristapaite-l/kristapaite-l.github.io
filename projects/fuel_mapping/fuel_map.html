UK Fuel Finder

Search any UK town, city, or postcode to compare live local E10 fuel prices on an interactive color-coded heatmap.

How This Tool Was Built

1. Data Processing

Processes standardized forecourt datasets, automatically cleaning coordinates and filtering out malformed pricing entries.

2. Geocoding Search

Translates postcodes or town names into latitude and longitude coordinates using postcodes.io and Nominatim APIs.

3. Dynamic Heatmap

Uses continuous RGB color interpolation (Green to Red) based on relative local price ranges within a 12km search radius.

4. Instant Price Labels

Map pins display exact rounded prices (e.g., 139.9p) directly on the marker, with detailed popups on click.
